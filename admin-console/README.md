# 平台运营后台（admin-console）

给系统运营者使用：管理商家（租户）账号、开通/停用、套餐/有效期占位、员工绑定、系统健康、错误聚合、修复工具、审计日志。

**边界：平台管理员看不到任何商家业务明细**（订单内容、菜品内容、顾客信息、营收明细、备注、手机号、地址）。`adminApi` 不实现业务读取接口，页面也没有这些入口。

## 部署

1. 把 `index.html / app.js / style.css` 上传到 CloudBase 静态托管，或发布到 GitHub Pages。
2. 云开发控制台 → 环境 → 安全配置 → **Web 安全域名**：加入控制台实际访问域名。
3. 云函数环境变量（云开发控制台 → 云函数）：
   - `adminAuth` / `adminApi`：`ADMIN_TOKEN_SECRET`（至少 16 位随机串）
   - `adminAuth` / `adminApi`：`ADMIN_BOOTSTRAP_PASSWORD`（仅用于首次创建管理员，创建后失效）
4. 部署 `adminAuth`、`adminApi` 云函数（云端安装依赖）。
5. 打开页面，填环境 ID（默认 `ordering-d0gyct6z1ff2afebd`），用管理员账号登录。

> 页面通过 CloudBase JS SDK 匿名登录后调用云函数；需在控制台开启匿名登录。token 存在 `sessionStorage`，退出即清。

## 首次管理员

`admins` 集合为空时，用 `ADMIN_BOOTSTRAP_PASSWORD` 对应的口令登录，会自动创建第一个管理员。创建成功后该口令立即失效，请随后在「管理员改密」里设置正式密码，并从云函数环境变量中删除 `ADMIN_BOOTSTRAP_PASSWORD`。

## 功能

- 商家列表：搜索、状态、今日订单数（计数）、员工数
- 新建/编辑商家、启用/停用、套餐/有效期占位、功能开关（停用下单 / 只许自提 / 并发上限）
- 员工绑定/解绑（直接输入 openid）
- 系统健康：云函数可达性、集合存在性与文档数、默认商家状态、支付模式、今日菜单是否发布、最近 24h 错误码分布
- 修复工具：重建索引提示、补默认配置、清理孤儿引用、重置员工绑定、吊销商家 token、强制刷新菜单缓存、重发支付回调（按 ID 盲操作，只返回条数/成功失败）
- 审计日志、错误聚合、管理员改密

## 安全建议

- 不要把初始密码发到群聊；只在自己的设备登录；退出时清 sessionStorage。
- 定期轮换 `ADMIN_TOKEN_SECRET`（轮换后旧 token 全部失效）。
- 控制台根权限一旦泄露等同平台运营权限，发现异常先吊销 token / 重置管理员密码。
